Case study 2026 · FIFA World Cup
Solo project · 39 days live

Delta26 — a World Cup prediction system that retrains itself after every match

An autonomous ML system that predicted all 104 FIFA World Cup 2026 matches live, retraining itself after every completed game and publishing irreversible predictions in real time — then fully decommissioned with a public post-mortem.

What it does

Live data collected in parallel from 6 sources, validated by a Groq LLM and Pydantic schema guards, then fed into a Dixon-Coles Poisson model, Monte Carlo simulation (10,000 runs), and XGBoost classifier running in parallel. Predictions served over Server-Sent Events through a FastAPI backend and Next.js frontend, with the model retraining on every completed result before the next kickoff.

Outcome

104/104 matches predicted. 46.2% live tournament accuracy — the honest number. 68.4% peak validation accuracy after the Round of 16. 8 model versions shipped across 39 days. Ran the full tournament on $0/month infrastructure. Post-tournament: git history cleaned, credentials rotated, infrastructure decommissioned, standalone case study site shipped.

Case study 2026 · Hackathon
~3 hrs · Solo · demoed live

Research Council — replacing confident AI answers with an auditable process

A multi-agent research system where independent agents gather evidence, a council of judges challenges it, and a Chair synthesizes a final verdict with confidence scores and cited sources — built and demoed live at Build with Replit: Pune Edition.

What it does

A Director breaks the question into 3 research angles. Three Researcher agents run in parallel — Evidence, Industry, and Skeptic — each calling Tavily for live web search then Groq for a sourced summary. A single Council call evaluates all findings through 3 judge personas in one response, each returning a verdict and confidence score. A Chair agent synthesizes everything into a final verdict with key findings, disagreement flagged, and cited sources. React renders all 4 stages as expandable cards.

Outcome

Built and demoed end-to-end in ~3 hours at the hackathon. A Chair-stage rate-limiting issue was caught and fixed before the demo. Runs reliably on tested questions. Working MVP — no production metrics. GitHub migration in progress.

Case study 2026 · Hackathon
Solo · first hackathon

SalesGuard — turning a company name into a research brief

An AI sales intelligence tool built in the Linkup Async Hackathon that researches any company in under a minute — pulling live news, scoring risk, and generating personalized outreach strategies.

What it does

A LangGraph 3-node pipeline: Linkup deep search pulls live news and filings, a custom keyword algorithm produces a 5–95 risk score, then Groq's llama-3.3-70b-versatile returns a structured JSON brief with an executive summary and outreach suggestions. FastAPI serves it; React renders a bento-grid dashboard with copyable suggestions and PDF export.

Outcome

Submitted to the Linkup Async Hackathon. Received direct written feedback from Linkup's founding team — strong idea, integration well done, main critique was that it reads more like a feature than a standalone product. Invited to keep building. Currently live and deployed.

04 — Engineering principles

How I think about building things.

These aren't rules — they're the defaults I fall back to when a decision is ambiguous, which is most of the time in applied AI work.

01

Learn by building.

I pick up a new tool by shipping something small with it, not by finishing a course first.

02

Ship before polishing.

A rough version that works teaches me more than a polished one that doesn't exist yet.

03

Measure before optimizing.

I check what's actually slow or wrong before assuming I already know.

04

Keep systems simple.

FastAPI, SQLite, and Streamlit before anything heavier, until a project proves it needs more.

05

Document everything.

If it's not written down, I end up re-explaining it to myself in three months anyway.

06

Every project teaches something.

Even the ones that don't ship teach me something useful for the next one.
